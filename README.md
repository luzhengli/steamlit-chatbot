# steamlit-chatbot
基于steamlit、langchain的AI对话机器人，目前仍在 beta 阶段，仅供学习。

# features
- [x] 支持基于本地文档的检索增强生成（RAG）
- [x] 支持对话记录存储（目前仅支持保存为 json 文件）、切换、新建
- [x] 支持多类型文件上传，如 pdf、markdown、 docx
- [x] 支持 conversion history in memory
- [ ] 支持 conversion history in databse
- [ ] 支持向量数据库持久化
- [ ] 支持多用户切换
- [ ] ...
